Identifier Methods: To check the content of a string and return either true or false. 


1)startswith:Checks whether a string starts with a particular character or substring.

Syntax: s.startswith(prefix, start, end)

prefix: Character or substring to check.

start and end: Optional positions to check within the string.



s = "Master jack chan"
s
'Master jack chan'


s.startswith('a')
False
s.startswith('M')
True
s.startswith('Master')
True

ex: Checking whether a product code starts with a particular category prefix(character/substring)


2)endswith:To check whether a string ends with a particular character or substring.

Syntax: string.endswith(suffix, start, end)

s.endswith('chan')
True

ex: Checking a filename extension.

file = 'python.jpg'
file.endswith('jpg')
True



3)islower():If string contains at least one case letter and all its cased letters are lowercase, It is return 'True'.

Synatx: s.islower()

ex: Checking the letter case of a username or text input.

'Python'.islower()
False
'python'.islower()
True



4)isupper(): If string contains at least one case letter and all its cased letters are Uppercase, It is return 'True'.

syntax: s.isupper()

ex: Checking uppercase coupon codes or product labels.

'Python'.isupper()
False
'PYTHON'.isupper()
True



5)is alpha():To check whether all character are alphabetic letters.
Note:  The string is  not empty.

Syntax: string.isalpha()

ex:Checking whether a field contains only letters, such as a name field. Real names can contain spaces, hyphens, and apostrophes.




6)is alnum(): Checks whether all characters are alphabetic letters or numeric digits, with no spaces or punctuation.

Syntax: string.isalnum()

ex: Checking a product code that allows only letters and numbers.




7)istitle():To check whether strings follow the first letter should capital and other remaining is small letter in each words in the string.


Syntax: string.istitle()

EX: Checking or validating the formatting of product names and headings.


8)isdentifier():Checks whether a string is a valid Python identifier — a name that can be used for a variable or function.

Syntax: string.isidentifier()

ex: Useful in code editors, developer tools, and applications that generate Python variable names. It is not a general-purpose username validator.


9)isspace(): Checks whether every character in a non-empty string is whitespace, such as spaces, tabs, or newlines.

Syntax: string.isspace()

ex: Detecting input that contains only spaces instead of actual text

10)isdecimal(): Checks whether every character is a decimal digit.

Syntax: string.isdecimal()

ex: checking whether an input contains decimal digits only, such as a numeric code

11)isdigit():Checks whether all characters are digits according to Python's broader Unicode digit definition.


syntax: string.isdigit()


ex:Checking digit-like text in general text processing


12)isnumeric():
Checks whether all characters are numeric according to Unicode's numeric definition. This includes decimal digits and certain other numeric characters, such as fractions.


Syntax: string.isnumeric()


ex: Working with Unicode numeric text. For validating prices or quantities
