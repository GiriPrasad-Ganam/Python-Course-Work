Dictionary: collection of data stored in key-value pairs.

Key: Used to identify or access the data.

Value: The actual information associated with the key.

it is defined curly braces{}


properties: 


1)key-pairs: 
----------------------------
A dictionary stores information in key-value pairs.


2)Mutable: 
--------------------------------
A dictionary is mutable, which means we can change, add, or remove elements after creating it.

3)Keys must be unique: 
----------------------------------------
Not allowed duplicate Values.



4)Values can be duplicated
-----------------------------------------------------
Dictionary values can contain duplicate data.
we can give duplicate value, Not duplicate keys.



a = {1:'jack', 2:'pop', 3:'jack',1:'jack'}
  
a
  
{1: 'jack', 2: 'pop', 3: 'jack'}   //values are allowed duplicate and Values are allowed duplicate.



5)key are allowed only string, interger, complex, Tuples.
------------------------------------------------------------
Dictionary keys must be hashable, such as strings, integers, and tuples containing only hashable elements.
