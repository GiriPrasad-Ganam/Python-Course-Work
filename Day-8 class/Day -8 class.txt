8)any:The any() function checks whether at least one element in an iterable is True.
- If at least one element is True, it returns True.
- If every element is False, it returns False.

Syntax: any(iterable)


ex: At least one product has a price greater than zero, so any() returns True


9)all:
The all() function checks whether all elements in an iterable are True.
- If every element is True, it returns True.
- If at least one element is False, it returns False.

Syntax: all(iterable)


ex:Every product price is greater than zero, so all() returns True.
